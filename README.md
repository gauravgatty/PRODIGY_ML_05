# 🍔 Food Calorie Detector

A modern web application that detects food items from images and estimates their calorie content.

🔗 Live Demo: https://prodigy-ml-05-4.onrender.com  
📂 GitHub Repo: https://github.com/your-username/food-calorie-detector

---

## 🚀 Features

- 📸 Upload food image  
- 🤖 Detect food item  
- 🔥 Estimate calories  
- 🎨 Modern dark neon UI  
- ⚡ Fast and lightweight deployment  

---

## 🛠 Tech Stack

- **Frontend:** HTML, CSS (Neon UI)  
- **Backend:** Flask (Python)  
- **Deployment:** Render  
- **ML (Local Training):** TensorFlow (used during development)

## ⚙️ How It Works

1. User uploads an image  
2. Image is sent to backend  
3. Backend processes image  
4. Returns:
   - Food name  
   - Estimated calories

## 🧠 Note

The model was trained locally using TensorFlow.  
For deployment, a lightweight version is used to ensure compatibility with cloud hosting.
